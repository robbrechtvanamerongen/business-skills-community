# Security policy

This repository distributes public AI agent instructions. Treat unexpected
instruction changes, dependency injection, unauthorized publication, and
credentials or non-public information in Git history as security concerns.

## Reporting

Use the repository's [private vulnerability reporting form](https://github.com/robbrechtvanamerongen/business-skills-community/security/advisories/new) if enabled. If unavailable, contact the repository owner privately through an established channel. Do not post sensitive details, credentials, or exploit payloads in public issues or pull requests.

Report the affected path, version or commit, impact, and a minimal safe
reproduction. Do not test against other users' accounts or installations.
No response-time commitment is made.

## Distribution controls

Only intentionally approved public content belongs here. See
[publication process](docs/publication-process.md) for the pre-publication
gate, review process, and incident handling. CI checks are defense in depth;
they cannot undo disclosure on a public branch or identify all secrets or
confidential information. Review every proposed file before public upload.

This policy does not grant a software license or authorize redistribution
beyond applicable rights.
